# Stacks

## Theory
A stack is a linear data structure that follows the Last-In-First-Out (LIFO) principle. Elements are added and removed from the top.

## Example Code (Python)
```python
stack = []
stack.append(1)  # Push
stack.append(2)
print(stack.pop())  # Pop: 2
```

## Practice Problem
Check if parentheses in a string are balanced using a stack.

## Key Points
- Used in function calls, undo operations, and expression evaluation.
- Python lists can be used as stacks.
