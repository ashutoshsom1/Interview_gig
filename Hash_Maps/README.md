# Hash Maps

## Theory
A hash map (dictionary) stores key-value pairs for fast lookup. Collisions are handled by chaining or open addressing.

## Example Code (Python)
```python
my_map = {}
my_map["a"] = 1
my_map["b"] = 2
print(my_map["a"])
```

## Practice Problem
Implement a hash map with collision handling using chaining.

## Key Points
- Hash maps provide average O(1) lookup.
- Good hash functions and collision handling are crucial.
