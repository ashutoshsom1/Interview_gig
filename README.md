# Interview Gig: Technical Interview Preparation

This repository is organized to help you master core computer science concepts for technical interviews, starting from scratch. Each topic is in its own folder with:
- Beginner-friendly theory/notes
- Example code (Python)
- Practice problems with solutions
- Key trade-offs and use cases

## Topics Covered
- Data Types
- Bitwise Operations
- String Operations
- Arrays
- Linked Lists (Singly, Doubly, Circular)
- Queues
- Stacks
- Heaps
- Trees (Binary, BST, Self-Balancing, Tries)
- Tree Traversals (BFS, DFS, Preorder, Inorder, Postorder)
- Graphs (Dijkstra, A*)
- Hash Maps (Collisions)
- Sorting Algorithms (Insertion, Selection, Merge, Quick)
- Time Complexities
- Programming Paradigms (Dynamic, OOP, Asynchronous, Functional)

Start with the README in each folder for a step-by-step guide and understand what things need attentions.
