# Trees

## Theory
A tree is a hierarchical data structure with a root node and child nodes. Special types include binary trees, BSTs, and self-balancing trees.

## Example Code (Python)
```python
class TreeNode:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
```

## Practice Problem
Write a function to find the height of a binary tree.

## Key Points
- Trees are used in databases, file systems, and more.
- Traversal methods: preorder, inorder, postorder, BFS, DFS.
