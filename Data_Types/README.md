# Data Types

## Theory
Data types define the kind of data a variable can hold (e.g., integer, float, string, boolean). Understanding data types is fundamental to programming.

## Example Code (Python)
```python
# Integer
a = 5
# Float
b = 3.14
# String
c = "Hello"
# Boolean
d = True
```

## Practice Problem
Create variables of each data type and print their types using `type()`.

## Key Points
- Data types affect memory usage and operations.
- Choosing the right data type improves performance and correctness.
