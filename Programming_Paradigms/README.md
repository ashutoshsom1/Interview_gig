# Programming Paradigms

## Theory
Programming paradigms are styles of programming. Key paradigms: Object-Oriented, Functional, Dynamic, Asynchronous.

## Example Code (Python)
```python
# Object-Oriented
class Animal:
    def speak(self):
        print("Sound")
# Functional
squared = list(map(lambda x: x*x, [1,2,3]))
```

## Practice Problem
Write a class and a pure function for the same task.

## Key Points
- Paradigms affect code structure and problem-solving approach.
- Learn when to use each paradigm.
