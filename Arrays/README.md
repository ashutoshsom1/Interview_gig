# Arrays

## Theory
Arrays are collections of elements, usually of the same type, stored in contiguous memory. In Python, lists are dynamic arrays.

## Example Code (Python)
```python
arr = [1, 2, 3, 4]
# Access
print(arr[0])
# Update
arr[1] = 10
# Append
arr.append(5)
# Remove
arr.remove(3)
```

## Practice Problem
Write a function to find the maximum element in an array.

## Key Points
- Arrays allow fast access by index.
- In Python, lists can store mixed types but are usually used for uniform data.
